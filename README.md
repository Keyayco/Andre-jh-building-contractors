# Andre JH Building Contractors website

A standalone website built with plain HTML, CSS and JavaScript. It has no build step, framework, package installation or dependencies.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish on GitHub Pages

In the repository's GitHub Pages settings, choose **Deploy from a branch**, select the default branch and the `/docs` folder, and save. The website and its photos are all included in this folder.

## Update business details

Edit the visible text and contact details in `index.html`. Phone links use `tel:+27716168459`; the WhatsApp number and enquiry message are in `script.js`. Replace images in `images/` to update the site's photos while keeping their existing filenames. Portfolio images are explicitly labelled as demonstrations and are not represented as completed company projects.
